Comment gérer tes sources et thèmes

Ajouter une source
1. Onglet Sources → "+ Ajouter une source"
2. Remplis le formulaire (nom, URL RSS, pays…)
3. Clique sur "Générer le JSON"
4. Copie la ligne JSON générée
5. Ouvre sources.json sur GitHub, colle la ligne avant le ] final
6. Commit + relance la collecte (Actions → Run workflow)
Ajouter un thème
1. Onglet Thèmes → "+ Ajouter un thème"
2. Choisis un thème pré-configuré OU crée ton propre thème
3. Remplis les mots-clés (séparés par des virgules)
4. Clique sur "Générer le JSON"
5. Copie le bloc généré dans themes.json sur GitHub
Bon à savoir
• Les mots-clés forts sont ceux qui suffisent à eux seuls à qualifier un article (ex : "corruption", "CAda", "lanceur d'alerte").
• Le poids permet de donner plus d'importance à un thème (ex : corruption à 1.5, transparence à 2).
• Un article peut avoir plusieurs thèmes s'il touche à plusieurs sujets.
