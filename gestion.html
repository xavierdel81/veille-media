Comment fonctionne l'exclusion de thème ?
Les thèmes que tu décoches sont ajoutés à un fichier themes-exclus.json. Le collecteur les ignorera à la prochaine collecte. Pour les réactiver, il suffit de les recocher.

Astuce : l'exclusion est réversible — rien n'est supprimé de themes.json.

Comment gérer tes sources et thèmes

Supprimer une ou plusieurs sources
1. Onglet Sources
2. Coche les sources à supprimer (colonne 🗑️)
3. Clique sur "Générer le sources.json épuré" (barre rouge en bas)
4. Copie le contenu affiché
5. Ouvre sources.json sur GitHub, remplace TOUT par le contenu copié
6. Commit + relance la collecte
Ajouter une source
1. Bouton "+ Ajouter une source"
2. Remplis le formulaire
3. Clique sur "Générer le JSON"
4. Copie la ligne générée dans sources.json avant le ]
Désactiver un thème (sans le supprimer)
1. Onglet Thèmes
2. Décoche les thèmes à exclure
3. Clique sur "Générer themes-exclus.json" (barre rouge en bas)
4. Crée/remplace le fichier themes-exclus.json sur GitHub avec le contenu copié
Ajouter un thème
1. Bouton "+ Ajouter un thème"
2. Choisis un preset OU crée ton propre thème
3. Remplis les mots-clés
4. Copie le bloc généré dans themes.json
